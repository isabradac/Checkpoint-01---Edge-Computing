# Checkpoint-01---Edge-Computing
Isadora Bradac RM - 569585 
Murilo Araujo RM - 573517
A atividade consiste no desenvolvimento de um sistema de monitoramento para a Vinheria Agnello, com foco na medição da luminosidade do ambiente utilizando Arduino e sensor LDR.
O sistema deve indicar o estado do ambiente por meio de sinais visuais e sonoros:
LED verde: condições adequadas
LED amarelo: nível de alerta
LED vermelho: condição crítica (com acionamento de buzzer por 3 segundos)
